# 現状の感想
- 良い点：
  学習が進むと決定境界が変わっていく様子が見えて、直感的にわかりやすい
- 物足りない点：
  何をどの順番で試せばよいかがわからず、少し触って終わってしまう
- 学習者がつまずいた点：
  学習率を変えると何が起きるのか、損失グラフの読み方がわからない

# 追加・改善したいこと（優先順）
1. ステップ形式のレッスンを追加する
   （例：「学習率を0.01と1.0で比べてみよう」のような課題を5つ）
2. 各レッスンの最後に、理解度を確かめる3択クイズを付ける
3. データの種類を選べるようにする（直線で分けられる点、円形、らせん形）

# 条件
- 既存の機能と操作方法は変えない
- 初学者にとって画面が複雑になりすぎないようにする
- ほかに学習効果が上がる案があれば、実装前に3つ提案する
- その他：
  自由に触れる「実験モード」と、順番に進む「レッスンモード」を切り替えられるようにする
