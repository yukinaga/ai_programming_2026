アクションのゲームを作ってください。

# 概要
- コンセプト：
  空から落ちてくるフルーツをカゴで受け止めるゲーム
- 対象プレイヤー：
  小学生から大人まで、ゲームに慣れていない人でも遊べる
- 動作環境：
  ブラウザで動くHTML1ファイル。パソコンとスマホの両方に対応

# ルール
- プレイヤーの操作：
  左右の矢印キー、またはスマホでは画面タッチでカゴを左右に動かす
- 目的：
  制限時間60秒の間に、できるだけ多くのフルーツを受け止める
- 失敗条件：
  爆弾を受け止めるとライフが1減り、ライフが0になるとゲームオーバー
- 得点・進行：
  りんご10点、ぶどう20点、メロン50点。ライフは3つ

# 見た目と音
- 雰囲気：
  明るくポップで、かわいい絵柄
- 効果音・BGM：
  受け止めたときと爆弾に当たったときに効果音。BGMはなし

# 必須の画面
  タイトル画面、プレイ画面、結果画面（スコア表示とリトライボタン付き）

# 制約
  外部の画像や素材は使わず、絵文字と図形で描く

まず動く最小限のものを完成させてください。
