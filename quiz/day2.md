## 小テスト：Pythonの基礎1

**問1（変数）**
`a = 123` と書いたあとに `print(a)` を実行すると何が起こりますか。「変数」「値」という言葉を使って説明してください。

**問2（コメント）**
コード中の `#` にはどのような役割がありますか。どんな場面で使うと便利かも含めて説明してください。

**問3（変数名）**
`dog_name` や `number321` は変数名として使えますが、`321number` は使えません。その理由を、変数名のルールとあわせて説明してください。

**問4（文字列）**
文章を変数に入れるにはどう書けばよいですか。また、`a = "Hello"`、`b = "World"` のとき `a + b` の結果がどうなるか説明してください。

**問5（四則演算）**
`a = 7`、`b = 3` のとき、`a / b`、`a // b`、`a % b` はそれぞれどのような結果になりますか。3つの演算子の違いがわかるように説明してください。

**問6（Bool値）**
Bool値とはどのような値ですか。また、比較演算子とBool値の関係を説明してください。

**問7（比較演算子）**
`c = 3`、`d = 4` のとき、`c >= d` と `c != d` の結果はそれぞれどうなりますか。理由とともに答えてください。

**問8（論理演算子）**
`a = 3`、`b = 4`、`c = 5` のとき、次の3つの結果とその理由を説明してください。
- `a < b and b < c`
- `a < b or b > c`
- `not a < b`
