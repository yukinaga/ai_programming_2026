## 小テスト：Pythonの基礎2

**問1（リストの基本）**
リストとはどのようなときに使うものですか。書き方のルールも含めて説明してください。また、`a = [2011, 2012, 2013, 2014, 2015]` のとき `a[1]` が何になるか、理由とともに答えてください。

**問2（リストの範囲指定）**
`b = 2016`、`c = [b, 2017, 20.1, "Hello", "Hi"]` のとき、`c[1:4]` の結果はどうなりますか。`[1:4]` が表す範囲の意味とあわせて説明してください。

**問3（リストの変更と追加）**
作成済みのリストの要素を変更する方法と、要素を追加する方法をそれぞれ説明してください。`e = ["Py", 543.21, 79, "thon"]` を例に使ってかまいません。

**問4（タプル）**
タプルとリストの共通点と違いを説明してください。また、どのような場合にタプルを使うほうがよいかも答えてください。

**問5（辞書）**
辞書はどのような仕組みでデータを格納しますか。`a = {"Taro":1985, "Hanako":1986}` を例に、値の取得、値の入れ替え、要素の追加の方法を説明してください。

**問6（if文）**
次のコードを実行すると何が表示されますか。`if`、`elif`、`else` がそれぞれどのように働くかを含めて説明してください。

```python
time = 20

if time < 12:
    print("Good morning!")
elif time < 17:
    print("Good afternoon!")
elif time < 21:
    print("Good evening!")
else:
    print("Good night!")
```

**問7（インデントとfor文）**
インデントとは何ですか。また、次のコードを実行すると何が表示されるか、`range(0, 6)` の意味とあわせて説明してください。

```python
for i in range(0, 6):
    print(i * 2)
```

**問8（while文）**
while文はどのようなループですか。次のコードの動きを説明し、`a += 1` の行がなかった場合にどうなるかも答えてください。

```python
a = 0
while a < 10:
    print(a)
    a += 1
```

**問9（分岐とループの組み合わせ）**
次のコードを実行すると何が表示されますか。処理の流れを順を追って説明してください。

```python
a = []
for i in range(0, 10):
    if i%2 == 0:
        a.append(i)

print(a)
```
